# Docker Basics Exercises

This repository contains hands-on exercises for learning the fundamentals of Docker. The exercises build from running containers and managing their inputs and ports to containerizing application projects, connecting services, publishing images, and deploying an application to the cloud.

## Exercises

| Folder | Topic |
| --- | --- |
| `1_07` | Use a shell script to make HTTP requests to a chosen website. |
| `1_08` | Build and run a web-server image. |
| `1_09` | Share a log file between the host and a container with a bind mount. |
| `1_10` | Publish a container port to the host. |
| `1_11` | Build and run a Spring Boot application in Docker. |
| `1_12` | Build and run a React frontend in Docker. |
| `1_13` | Build and run a Go backend in Docker. |
| `1_14` | Containerize and connect the frontend and backend. |
| `1_15` | Publish an image to a container registry such as Docker Hub. |
| `1_16` | Deploy an application to the cloud. |

## Getting started

- Install Docker Engine or Docker Desktop and make sure the Docker CLI is available.
- Work through the numbered exercise folders in order, following the instructions for the associated course exercises.
- Each folder contains the files relevant to that task, such as Dockerfiles, source code, or command notes. The `tests/` directory contains checks for several exercises.

Some later exercises use additional tools or runtimes, including Java, Node.js, and Go. Check the README in an exercise folder for project-specific setup instructions.
